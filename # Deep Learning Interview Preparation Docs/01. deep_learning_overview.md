# Part 1: Fundamentals of AI, ML, and DL

### Q1. What is Artificial Intelligence (AI)?

**Answer:** Artificial Intelligence is the broad field of creating machines that can perform tasks in ways that are similar to human intelligence. It is the larger field under which Machine Learning and Deep Learning sit.

### Q2. What is Machine Learning (ML)?

**Answer:** Machine Learning is a subfield of AI in which machines learn patterns and relationships from data instead of being given every rule explicitly. A model learns from examples and uses what it has learned to make predictions on new inputs.

### Q3. What is Deep Learning (DL)?

**Answer:** Deep Learning is a subfield of Machine Learning based on artificial neural networks with multiple layers. These networks learn relationships between inputs and outputs and can automatically learn useful features from raw data.

### Q4. How are AI, ML, and DL related?

**Answer:** They form a nested hierarchy: Deep Learning is part of Machine Learning, and Machine Learning is part of Artificial Intelligence. Therefore, Deep Learning is not separate from or a replacement for Machine Learning; it is one approach within it.

### Q5. Is Deep Learning a competitor to Machine Learning?

**Answer:** No. Deep Learning belongs to Machine Learning. The two approaches aim to learn relationships between inputs and outputs, but they use different machinery and have different strengths, costs, and practical requirements.

### Q6. What is the basic objective of a Machine Learning model?

**Answer:** Its objective is to learn a relationship between input data and an output. For example, a house-price model learns from details such as area, location, and number of rooms, along with known sale prices, so it can estimate the price of a new house.

### Q7. What changes when we move from traditional Machine Learning to Deep Learning?

**Answer:** The overall goal remains the same: learning a relationship between inputs and outputs. What changes is the machinery. Traditional ML mainly uses conventional statistical techniques and algorithms, while Deep Learning uses neural networks and their architectures.

### Q8. Why is Deep Learning described as being inspired by the human brain?

**Answer:** Neural networks borrow an idea from the structure of the human brain: connected processing units working together. An artificial neural network is a logical computational structure inspired by certain aspects of biological neural systems. It is not itself a human brain.

# Part 2: Artificial Neural Networks

### Q9. What is an Artificial Neural Network (ANN)?

**Answer:** An ANN is a network of connected computational units, often called perceptrons, nodes, or neurons. These units are arranged into layers and process numerical information by passing it through weighted connections.

### Q10. What is a perceptron in the context of an ANN?

**Answer:** A perceptron is a fundamental unit of a neural network. In a network diagram, it is commonly represented by a circle and may also be called a node or neuron.

### Q11. What do the connections between perceptrons represent?

**Answer:** Connections represent the links through which information passes between units in the network. Each connection carries a weight that represents the strength of that connection.

### Q12. What is a weight in a neural network?

**Answer:** A weight is a numerical value associated with a connection between two units. It controls the strength or influence of information travelling along that connection. During learning, the network adjusts its weights.

### Q13. What is a layer in a neural network?

**Answer:** A layer is a group of perceptrons or nodes arranged together in the network. A basic neural network contains an input layer, one or more hidden layers, and an output layer.

### Q14. What is the role of the input layer?

**Answer:** The input layer is where the data enters the neural network. It receives the input information that the network will process.

### Q15. What is the role of hidden layers?

**Answer:** Hidden layers sit between the input and output layers. They process information and learn useful patterns or representations. A network can contain multiple hidden layers.

### Q16. What is the role of the output layer?

**Answer:** The output layer produces the network's final result or prediction.

### Q17. What does the word “deep” mean in Deep Learning?

**Answer:** “Deep” refers to the number of hidden layers in a neural network. A network with relatively few hidden layers is described as shallow, while a network with many hidden layers is described as deep. It does not mean that the model thinks profoundly.

### Q18. What is a neural network architecture?

**Answer:** An architecture is the overall design or structure of a neural network. It includes the arrangement of nodes, the connections between them, the weights, and the network's overall structure. Different architectures are designed for different kinds of problems.

# Part 3: Types of Neural Networks

### Q19. What are the main neural network types introduced in the chapter?

**Answer:** The chapter introduces four types: Artificial Neural Networks (ANNs), Convolutional Neural Networks (CNNs), Recurrent Neural Networks (RNNs), and Generative Adversarial Networks (GANs).

### Q20. What is a CNN, and what kind of data is it associated with?

**Answer:** CNN stands for Convolutional Neural Network. The chapter associates CNNs primarily with image-related data and computer-vision tasks.

### Q21. What is an RNN, and what kind of data is it associated with?

**Answer:** RNN stands for Recurrent Neural Network. The chapter associates RNNs with sequential data, including speech, time-related data, and text.

### Q22. What is a GAN, and what is it associated with?

**Answer:** GAN stands for Generative Adversarial Network. It is associated with generating new content.

### Q23. How would you choose among CNN, RNN, and GAN at a high level?

**Answer:** Start with the nature of the task. CNNs are associated with image-related problems, RNNs with sequences such as speech, time-related data, and text, and GANs with generating new content. The chapter presents these as broad associations rather than exhaustive rules.

# Part 4: Representation Learning and Features

### Q24. What is a feature in Machine Learning?

**Answer:** A feature is a measurable clue or characteristic in the data that a model can use to make a prediction. In a house-price problem, examples include area, location, and number of rooms.

### Q25. What is feature extraction?

**Answer:** Feature extraction is the process of pulling useful measurements or information out of raw data so that a model can use them.

### Q26. What is feature engineering?

**Answer:** Feature engineering is the process of designing and creating useful features from the available data. In traditional ML, this often requires human knowledge of the problem.

### Q27. What is feature selection?

**Answer:** Feature selection means choosing which available features are worth keeping for a model. It is different from feature extraction, which creates or obtains features from raw data.

### Q28. What is representation learning?

**Answer:** Representation learning, also called feature learning, is the ability of a model to learn useful features or representations automatically from data. In Deep Learning, the network learns these representations instead of depending entirely on manually designed features.

### Q29. How does traditional Machine Learning approach a dog-versus-cat image-classification problem?

**Answer:** A traditional ML approach typically requires a person to decide which visual clues may be useful and convert them into features. Possible hand-crafted features might include size, colour, and physical attributes. The algorithm then learns from those features to classify the image.

### Q30. How does Deep Learning approach the same dog-versus-cat problem?

**Answer:** A Deep Learning model receives the image in a suitable format and learns useful visual features from the data. Instead of requiring a person to specify every clue, the network learns representations through its layers.

### Q31. How do neural network layers progressively learn features?

**Answer:** The chapter describes a progression from simple to complex features:

1. Initial layers learn primitive patterns such as edges and lines.
2. Intermediate layers combine these into shapes and more complex patterns.
3. Deeper layers learn richer structures and parts of objects, such as parts of an animal's face.
4. The output layer produces the final prediction.

### Q32. Why is representation learning considered one of Deep Learning's major advantages?

**Answer:** It reduces the need for people to manually design and extract every useful feature. This is particularly valuable when useful clues are difficult to describe or hand-craft, as can happen with raw images, audio, or text.

### Q33. Does automatic feature learning mean that human effort is no longer needed?

**Answer:** No. It reduces much of the manual feature-engineering work, but people still need to prepare data, choose an appropriate problem and model, provide sufficient training data and computing resources, and evaluate the results carefully.

# Part 6: Machine Learning vs Deep Learning

### Q39. What are the five dimensions used in the chapter to compare ML and DL?

**Answer:** The five dimensions are:

1. Data dependency.
2. Hardware requirements.
3. Training time versus prediction time.
4. Feature extraction.
5. Interpretability.

### Q40. How do Machine Learning and Deep Learning differ in their data requirements?

**Answer:** Traditional ML can often work well with comparatively small datasets. Deep Learning is generally more data-hungry and tends to benefit from larger amounts of training data. The chapter also illustrates that traditional ML performance may flatten as more data is added, while Deep Learning performance can continue to improve as data grows.

### Q41. Why is Deep Learning described as data-hungry?

**Answer:** Deep Learning models learn useful representations from data rather than relying entirely on manually specified features. They generally need many examples to learn reliable patterns, particularly when the input is complex, such as images, audio, or text.

### Q42. How do the hardware requirements of ML and DL differ?

**Answer:** Traditional ML models can usually be trained on an ordinary CPU. Deep Learning involves large numbers of matrix operations and benefits significantly from GPUs, which can perform many calculations in parallel. Deep Learning can still run on a CPU, but training is usually slower.

### Q43. Why are GPUs useful for Deep Learning?

**Answer:** Neural networks perform many matrix operations. GPUs are designed to handle large numbers of calculations in parallel, which can accelerate the computations involved in training neural networks. The chapter also identifies NVIDIA's CUDA programming support as an important development for using GPUs in Deep Learning.

### Q44. Does Deep Learning require a GPU to run?

**Answer:** No. A Deep Learning model can run on a CPU. A GPU is beneficial because it can make the computations significantly faster, especially for larger models and datasets.

### Q45. How does training time differ between traditional ML and Deep Learning?

**Answer:** Traditional ML models generally train faster. Deep Learning training can take much longer because of the size of the datasets, the complexity of the networks, and the large number of computations involved. The chapter notes that some large training tasks can take weeks or longer.

### Q46. Is prediction time always slower for Deep Learning than for traditional ML?

**Answer:** No. Training time and prediction time are different operations. Once trained, a Deep Learning model can make predictions very quickly. Traditional ML prediction time depends on the algorithm; the chapter gives K-Nearest Neighbors (KNN) as an example that can take considerable time to make a prediction.

### Q47. How does feature extraction differ between ML and DL?

**Answer:** Traditional ML often relies on people to extract, engineer, or select useful features before training. Deep Learning can learn useful features automatically inside the neural network through representation learning. This reduces the need for manual feature engineering.

### Q48. What is interpretability?

**Answer:** Interpretability is the ability to understand why a model produced a particular prediction. An interpretable model allows a person to examine or trace the factors and steps that contributed to its output.

### Q49. Why are Deep Learning models often described as black boxes?

**Answer:** Deep Learning networks can contain many layers and weights, and the features they learn are not always easy to interpret. A model may produce a prediction, but it can be difficult to explain exactly which internal features or calculations led to that result.

### Q50. Why are Logistic Regression and Decision Trees often easier to interpret?

**Answer:** In Logistic Regression, the learned weights attached to features can be inspected to understand how features influence a prediction. In a Decision Tree, the sequence of decisions can be followed like a flowchart. These structures often make their predictions easier to explain than those of a deep neural network.

### Q51. Does Deep Learning always outperform traditional Machine Learning?

**Answer:** No. Deep Learning is not automatically the best choice. When data is limited, hardware is constrained, or explanations are important, traditional ML may be more suitable. The correct choice depends on the project's data, resources, and requirements.

### Q52. Explain the “needle versus sword” analogy used in the chapter.

**Answer:** The analogy means that a more powerful tool is not automatically the right tool. Traditional ML is compared to a needle and Deep Learning to a sword. If the problem only requires a needle, using a sword adds unnecessary cost and complexity. Choose the method that fits the problem rather than the one that sounds more impressive.

# Part 7: Why Deep Learning Took Off Around 2012

### Q53. If Deep Learning research began decades ago, why did it become widely successful much later?

**Answer:** The chapter explains that five factors had to mature together: large datasets, powerful hardware, accessible frameworks and libraries, useful architectures and transfer learning, and an active community of researchers and developers. Together, these factors made it practical to build and train Deep Learning systems at scale.

### Q54. What are the five factors behind Deep Learning's growth described in the chapter?

**Answer:**

1. **Data:** Large datasets provide examples from which models can learn.
2. **Hardware:** GPUs and specialised processors accelerate the required computations.
3. **Frameworks and libraries:** Tools simplify neural network development.
4. **Architectures:** Established designs and pretrained models provide starting points for different tasks.
5. **Community:** Researchers, engineers, teachers, students, and learning communities develop and share knowledge.

### Q55. How did smartphones and cheaper internet access contribute to Deep Learning's growth?

**Answer:** The spread of smartphones and the lower cost of internet access led to more people using digital services and applications. Those interactions generated enormous amounts of data. This increased the availability of data that could potentially be used to develop and train models.

### Q56. Why is raw data not necessarily suitable for supervised training?

**Answer:** Supervised learning requires examples with correct labels. For example, a collection of animal photographs is not enough on its own for a supervised dog-versus-cat classifier. The images need labels identifying which ones contain dogs and which contain cats.

### Q57. What is labelled data?

**Answer:** Labelled data is data that has the correct answer or category attached. For example, an animal photograph tagged as “dog” is a labelled example. Labels allow a supervised model to learn the relationship between an input and its target output.

### Q58. What role did organisations such as Microsoft, Google, and Facebook play in the availability of datasets?

**Answer:** The chapter explains that large companies invested in converting raw data into labelled datasets and made many datasets publicly available. This allowed researchers to download and use datasets without having to build every dataset from scratch.

### Q59. What is Moore's Law, as described in the chapter?

**Answer:** Moore's Law describes the observation that the number of transistors that can be placed on a chip roughly doubles every two years, while the cost per transistor falls. The chapter uses it to illustrate the long-term improvement in computing hardware.

### Q60. What is parallel processing, and why does it matter for Deep Learning?

**Answer:** Parallel processing means performing many calculations at the same time instead of completing them one after another. Since neural network training involves many matrix operations, parallel processing can accelerate the work. GPUs are particularly useful for this type of computation.

### Q61. What are FPGA, ASIC, TPU, Edge TPU, and NPU?

**Answer:** The chapter introduces these as specialised hardware options:

- **FPGA (Field Programmable Gate Array):** Programmable hardware that can be configured for particular operations.
- **ASIC (Application-Specific Integrated Circuit):** A chip designed for a specific application or workload.
- **TPU (Tensor Processing Unit):** Google's specialised hardware for Deep Learning operations.
- **Edge TPU:** A TPU variant intended to run models on smaller devices near where data is produced.
- **NPU (Neural Processing Unit):** Hardware designed to accelerate neural network operations.

### Q62. Which hardware might be considered for different Deep Learning situations, according to the chapter?

**Answer:** The chapter gives the following broad guide: a CPU can be used to start small projects; a GPU is useful for training larger neural networks; a TPU can be considered for specialised Deep Learning workloads; and mobile CPUs, GPUs, DSPs, or NPUs can be used for models on smartphones. Edge TPUs or NPUs may be relevant for small devices such as smartwatches or smart glasses.

# Part 8: Frameworks, Architectures, and Transfer Learning

### Q63. Why are Deep Learning frameworks and libraries important?

**Answer:** They handle much of the lower-level implementation, such as the operations needed to build and train neural networks. This allows developers to focus more on solving the application problem instead of implementing every operation from scratch.

### Q64. What is TensorFlow?

**Answer:** TensorFlow is a Deep Learning framework released by Google in 2015. The chapter describes it as a broadly usable framework that followed Google's internal DistBelief system.

### Q65. What is Keras, and how does it relate to TensorFlow?

**Answer:** Keras is a user-friendly interface that made it easier for developers to use TensorFlow's functionality. The chapter notes that TensorFlow 2.0 integrated Keras in 2019.

### Q66. What is PyTorch, and which organisation is associated with its development in the chapter?

**Answer:** PyTorch is a Deep Learning framework that the chapter associates with Facebook's development efforts beginning around 2016. It became especially popular among researchers.

### Q67. What is the broad usage pattern between TensorFlow and PyTorch described in the chapter?

**Answer:** The chapter associates TensorFlow and Keras more commonly with industry-driven applications and PyTorch more commonly with research-oriented applications. It also clarifies that these are usage patterns, not strict rules.

### Q68. Name some tools mentioned in the chapter that make it easier to build Deep Learning applications.

**Answer:** The chapter mentions Google AutoML, Microsoft Custom Vision, and Apple Create ML as tools that can lower the barrier to building Deep Learning applications.

### Q69. Why can designing a neural network architecture from scratch be expensive?

**Answer:** A developer may need to try multiple architectures, train each one, test them, and compare their results. This consumes time, computing resources, and money.

### Q70. What is transfer learning?

**Answer:** Transfer learning is the practice of reusing an existing trained architecture or model for a new problem. Instead of starting from scratch, a developer can build on work that has already been done.

### Q71. How does transfer learning save time and resources?

**Answer:** Researchers may already have designed and trained a suitable architecture on a relevant dataset. Reusing that model avoids repeating all the design and training work, reducing development time and computational cost.

### Q72. Give examples of architectures and the tasks associated with them in the chapter.

**Answer:** The chapter provides these examples:

| Task | Architecture |
|---|---|
| Image classification | VGGNet |
| Text classification and NLP-related tasks | Transformer |
| Image segmentation | U-Net |
| Image translation | Pix2Pix |
| Object detection | YOLO |
| Generation tasks | WaveNet |

# Part 9: Choosing Between ML and DL in a Project

### Q73. How would you decide whether to use traditional ML or Deep Learning for a new project?

**Answer:** The chapter recommends checking several factors:

1. **Data type:** Structured tables with meaningful columns often favour ML; raw images, audio, or text may favour DL.
2. **Dataset size:** A small dataset often favours ML; a very large dataset can make DL more practical.
3. **Hardware:** Limited to a CPU? ML may be a sensible starting point. A GPU makes larger DL projects more practical.
4. **Feature availability:** If useful features can be hand-crafted, ML may be sufficient. If they are difficult to specify, DL's representation learning can help.
5. **Explainability:** If decisions must be explained, favour interpretable ML models.
6. **Pretrained models:** Check whether a suitable pretrained architecture is available for transfer learning.
7. **Baseline comparison:** When uncertain, train a simple ML baseline first and compare it with the more expensive DL approach.

### Q74. Why does the chapter recommend starting with a simple ML baseline when uncertain?

**Answer:** A simple ML baseline provides a practical point of comparison. It helps establish whether Deep Learning's additional data, hardware, and development costs produce enough benefit to justify using it.

### Q75. Why is classical ML a natural fit for the chapter's stroke-prediction example using patient records?

**Answer:** The example uses structured data such as age, hypertension, glucose level, and BMI. The dataset is described as limited, the features already exist as meaningful columns, and explanations are valuable in a medical setting. The chapter therefore presents classical models such as Logistic Regression or Decision Trees as a natural fit.

### Q76. Why does the chapter suggest Deep Learning for detecting signs of stroke from brain-scan images?

**Answer:** Brain scans consist of raw image pixels, and it is difficult to hand-craft a complete set of useful image features. If a large labelled image dataset is available, a CNN can learn visual representations. The chapter suggests using a pretrained CNN through transfer learning as a possible approach.

### Q77. How do the traditional ML and Deep Learning pipelines differ?

**Answer:** In a traditional ML pipeline, raw data is cleaned and useful features are engineered before the model is trained. In a Deep Learning pipeline, preprocessing may still be needed, but much of the feature learning happens inside the neural network. The key shift is that the feature-engineering work moves into the model.

# Part 10: Scenario-Based and Deeper Interview Questions

### Q78. You have a small tabular dataset, limited computing resources, and a requirement to explain every prediction. Which approach would you try first, and why?

**Answer:** I would start with traditional Machine Learning. The dataset is small, the available hardware is limited, and interpretability is important. Models such as Logistic Regression or Decision Trees are reasonable starting points because they can work with structured features and are generally easier to explain.

### Q79. You need to classify millions of labelled images, and a suitable pretrained image model is available. Which approach would you consider?

**Answer:** I would consider a CNN-based Deep Learning approach and investigate transfer learning. The task involves raw image data, a large labelled dataset is available, and a pretrained architecture can reduce the time and resources needed to build a model from scratch.

### Q80. A team has millions of photos collected from an online platform. Can it immediately use them to train a supervised dog-versus-cat classifier?

**Answer:** Not necessarily. The photos may be raw and unlabelled. For supervised dog-versus-cat training, the team needs labels identifying which images contain dogs and which contain cats. The size of a dataset does not remove the need for suitable labels.

### Q81. A Deep Learning model performs poorly because only a small number of training examples are available. What does the chapter suggest about this situation?

**Answer:** Deep Learning is generally data-hungry and may not be the best choice when the dataset is small. A traditional ML model may perform better in that situation. I would first consider a classical ML baseline and also check whether an appropriate pretrained model could help.

### Q82. A neural network gives an accurate prediction, but the organisation cannot explain why it made that prediction. What issue does this illustrate?

**Answer:** This illustrates the interpretability or black-box problem. Deep Learning models can learn complex internal representations, but it may be difficult to identify exactly which internal features led to a particular prediction. This can be especially serious in settings where decisions need to be justified.

### Q83. A model takes a long time to train but gives predictions quickly after training. Is that contradictory?

**Answer:** No. Training and prediction are different operations. Training requires the model to learn its parameters from data and can be computationally expensive. Prediction uses the trained model to process new inputs, and that operation can be much faster.

### Q84. A developer wants to build a neural network for image segmentation but does not want to design everything from scratch. What idea from the chapter could help?

**Answer:** The developer could investigate transfer learning and an existing architecture such as U-Net, which the chapter associates with image segmentation. Reusing an established architecture can reduce design and training effort.

### Q85. Explain how the five factors behind Deep Learning's growth depend on one another.

**Answer:** Large datasets provide the examples required for learning. Hardware makes the large computations practical. Frameworks and libraries make it easier to implement models. Architectures provide effective designs and pretrained starting points. The community develops, tests, applies, and shares these advances. The factors reinforce one another; progress in only one area would not have been enough to make Deep Learning broadly practical.

### Q86. How can the same Deep Learning approach be useful in fields as different as medical imaging, speech recognition, and board games?

**Answer:** The underlying idea is to learn useful representations and relationships from data using neural networks. Different architectures and data formats can be used for different tasks, but the broader learning approach applies across many domains. The chapter highlights this wide applicability as one reason for Deep Learning's popularity.

### Q87. What single idea connects Deep Learning's advantages and disadvantages?

**Answer:** Deep Learning moves much of the work of finding useful features from the human to the machine. This automatic feature learning makes it useful for complex data and many different tasks. However, it also creates a need for more data and computation, and can make the model's internal decisions harder to explain.

### Q88. Does automatic representation learning remove the need for data preparation?

**Answer:** No. The chapter says that Deep Learning reduces the need for manual feature engineering, not all human effort. Data still needs to be prepared in a suitable format, and the project still requires appropriate data, model selection, computing resources, and evaluation.

## Interview-ready closing summary

Deep Learning is a subfield of Machine Learning that uses multi-layer neural networks to learn representations from data. Its key distinction from traditional ML is that it can learn useful features automatically instead of relying entirely on human-designed features. This makes it powerful across data types such as images, speech, and text, but it generally requires more data and computing resources and can be harder to interpret. Its growth depended on the combined development of datasets, hardware, frameworks, architectures, and an active community. Deep Learning does not replace traditional ML; the appropriate choice depends on the problem and its constraints.
